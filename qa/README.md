# Light suite QA

`light.py` checks four connection profiles using the final suite JAR and cached exact libraries. It preserves a hashed copy of the production bundle, runs disposable localhost worlds, checks per-module native decisions, confirms several in-world frames, checks client-observed red glow Chalk block/state and item-slot packets including damage/custom-name preservation, verifies generated pack loading for fallback clients, and verifies the exact Defaulted dropfix artifact. No original JAR, launcher profile, or existing world is changed.

The user confirmed the private official SSO26.3 input and authorized full suite testing on 2026-10-04. The separately named ChatGPT SSO port remains paused. See `../docs/VALIDATION.md` for completed evidence and remaining acceptance steps.

Tests are intentionally bounded: no exhaustive gameplay matrix or settings UI automation is included. `--extended-only` checks reconfiguration, reconnect in the same client process, and a deliberate one-module capability mismatch. `--integrated-only --world-template <disposable-world>` checks physical-client singleplayer with and without Polymer. `--client-polymer-only` checks the matching suite with client Polymer installed. `runs/` is development-only and must be excluded from source/release publication, except selected sanitized evidence files if desired. Logs can contain disposable offline profile IDs and machine-local paths.
