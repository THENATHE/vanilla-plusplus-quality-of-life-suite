# 1.4.0 connected toolbox verification

Published BRBR 1.11.1 with Polymer and local BRBR 1.11.2 without Polymer each passed eight connected crafting cases against the same final suite artifact. Each profile covers leather and netherite storage, both toolbox crafting sizes, ordinary and maximum crafting, recipe-book placement and ghost recipes, viewport bounds and exact item conservation. The floating panels appear in the retained screenshots. Input artifacts and executed fixture source/class hashes are retained for each profile.

These tests call real screen/widget callbacks and send normal inventory packets. They do not independently validate every BRBR control or physical keyboard/mouse input. Historical beta evidence remains unchanged.
