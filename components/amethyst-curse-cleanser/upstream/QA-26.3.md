# Minecraft 26.3 verification — Amethyst Curse Cleanser 1.0.1+26.3

Built with Gradle 9.6.0, Loom 1.17.19, Fabric Loader 0.19.5 and the real Minecraft 26.3 artifact. JDK 26 compiles with Java 25 release targeting. The new inventory API requires an explicit prediction mode; echo shard rewards use `Prediction.SERVER_ONLY`.

A separate QA mixin tested the packaged production JAR in a new temporary Minecraft 26.3 world. Both grindstone input orders and the smithing table passed: both curses removed, Unbreaking retained, name and durability retained, one gear item and one amethyst consumed, one echo shard rewarded, original input stack not mutated, ordinary uncursed gear rejected.

The same checks passed with the packaged Surveyor 1.2.5+26.3 and Tinkerer's Smithing 2.8.2+26.3 installed together with Fabric API 0.161.0+26.3. Production mixin injection and server startup/shutdown succeeded. Logs are retained in `qa/results/26.3/`. The development worlds were not modified.

Artifact: `build/libs/amethyst-curse-cleanser-1.0.1+26.3.jar`.
SHA-256: `5ec26e2a0010dfdee82aa5cb27664314150a4daa36deadc10f0c659f399507b6`.

No interactive client session was required for this server-side mod's crafting tests. Full-inventory dropping and shift-click behavior were not separately exercised.
