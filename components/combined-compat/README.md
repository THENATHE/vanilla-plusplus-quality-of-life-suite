The coordinator declares `1.1.0+26.3` and is nested in stable suite `1.1.0+26.3` on `main`. Protocol v2 negotiates 11 feature capabilities; the outer suite includes 16 nested modules.

This suite variant keeps the module code and IDs from the developer-target combined shim. It replaces the independent handshake with `SuiteCapabilities`, removes UUID override storage/commands/recovery tasks, and schedules the shared negotiation exactly once before Fabric registry synchronization. Server mixins are also available in integrated-server processes; the current validation guide distinguishes integrated-server coverage from dedicated-server evidence. Native Tool Pouch detection for clients running the original mod remains available through existing payload channels.
